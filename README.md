# Superstore Sales Analytics Dashboard

An end-to-end Power BI dashboard analyzing sales, profit, and customer 
performance across a retail dataset, built to practice data modeling, 
DAX, and executive-level BI storytelling.

## Overview
- 7-page report: Overview, Product, Customer, Regional, Returns, 
  Forecast, and a drillthrough Detailed Info page
- $22.97L in sales, 5,009 orders, 793 customers analyzed
- Normalized data model with fact/dimension tables and 30+ DAX measures

## Key Findings
- Identified that a 0.7-point YoY profit margin decline was driven by 
  Binders (margin dropped 20.6% → 10.5%) — the top-selling Office 
  Supplies sub-category
- Traced Central region's weak margin (7.92%) to two underperforming 
  states, Texas and Illinois, both posting margins below -15%
- Found 10 states currently unprofitable, with New York as the 
  strongest large market (23.8% margin) vs. California (16.7%) on 
  similar sales volume

## Features
- **Dynamic Top/Bottom N filtering** on product and customer visuals
- **Drillthrough navigation** from summary tables to transaction-level detail
- **12-month sales/profit forecast** using seasonal trend analysis (95% CI)
- **Trend-based target gauge** benchmarking projections against 
  historical average growth
- **Collapsible slicer panel** with Date, Category, Sub-Category, 
  Region, and State filters
- Custom conditional formatting, insight callouts per page, and a 
  consistent visual design system
